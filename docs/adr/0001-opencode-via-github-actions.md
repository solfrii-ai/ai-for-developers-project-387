# Интеграция OpenCode через GitHub Actions

**Статус:** accepted

## Решение

OpenCode используется в двух сценариях:

- `opencode` — ручное взаимодействие через команду `/opencode` в начале комментария. Workflow использует OIDC и GitHub App, поскольку агент может изменять код и создавать PR.

**Общие инварианты:**

- Основная и small-модель: `opencode/deepseek-v4.1-flash`.

## Безопасность

Для `issue_comment` в `opencode.yml` принят риск `dangerous-triggers`, поскольку workflow получает OIDC-токен и доступ к API-ключу.
Проверка инициатора не устраняет prompt injection. Исключение пересматривается до **2027-02-15**, а также при изменении триггеров или аутентификации.
